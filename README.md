- 🛒 **استوديو إعلانات التجارة والمنتوجات (جديد v1.35):** حطّ تصاور المنتوج + السوم بالدينار + نمرة الواتساب ويخرج إعلان بيع 3D جاهز للـ Sponsoring.
- 🗺️ **استوديو الخرائط المتحرّكة والوثائقيات (جديد v1.35):** طيران كاميرا فوق الخريطة من مدينة لمدينة بأسهم مضيئة وتعليق وثائقي عميق.
- 🏆 **استوديو التوب 5 + مصمّم السلايد والكاروسيل (جديد v1.35):** فيديوهات عدّ تنازلي من #5 إلى #1 + تصميم 6 شرائح كاروسيل 1080p لإنستغرام وتيك توك.
- 🎙️ **مبدّل طبقات الصوت + تنقية الضجيج + ملصقات التفاعل + تجربة Pro 24 ساعة (جديد v1.35):** راوي سينمائي عميق، صوت غامض بوليسي، تنقية ضجيج الشارع في المونتاج، وتجربة مجانية لـ Mkachekh Pro.
- 📰 **استوديو الخبر العاجل والترند (جديد v1.34):** حطّ خبر أو رابط أو Screenshot ويخرج ريل إخباري احترافي بشريط عاجل متحرّك وتعليق صوتي.
- 📱 **وضع الشاشة المقسومة TikTok Split-Screen + دقّة 1080p Full HD (جديد v1.34):** تقسيم الشاشة بمشاهد مريحة للعين لرفع نسبة المشاهدة + حفظ «ستايل قناتي» بضغطة وحدة.
- 📁 **مكتبة أعمالي وإدارة المساحة + تدقيق الترجمة + صوت مجاني بلا مفتاح (جديد v1.34):** تعليق صوتي يخدم حتّى بلا مفتاح (عربي، تونسي، فرنسي، إنجليزي)، تعديل الكلام المكتوب قبل التصدير، ومحرّك صور مجاني إضافي (AI Horde).
- 💬 **فيديوهات محادثات متحرّكة:** محادثات واتساب، إنستغرام DM وآيفون تطلع مساج بمساج مع أصوات التنبيه وقراءة بصوتين.
- 🎙️ **استوديو البودكاست والمناظرة 3D (جديد):** حوار أو مناظرة ساخنة بين مذيعَين مع موجات صوتية تتفاعل مع الكلام لحظة بلحظة.
- ⚽ **استوديو الكورة والمقارنات VS (جديد):** مباريات ونتائج حيّة من رابطة أبطال إفريقيا وأوروبا والدوريات الكبرى مع شعارات الفرق ومقارنات متحرّكة وتعليق حماسي.
- 🔗 **تحويل أي رابط لفيديو (جديد):** الصق رابط خبر، مقال، ويكيبيديا أو يوتيوب ويتحوّل لفكرة وهوك وسكريبت جاهز.
- ⚡ **معاينة حيّة فورية + طبيب الهوك وفلاتر الصوت (جديد):** شوف الفيديو في ثانية قبل الرندر، قيّم قوّة أوّل 3 ثواني من 100، وصفّي صوتك بفلاتر استوديو بدون إنترنت.
- 🧠 موّجه ذكاء تلقائي: يخدم مباشرة حتّى بلا مفتاح، ويدمج مفاتيحك المجانية (Groq، Cerebras، Google Gemini، Mistral، GitHub Models، Cloudflare، Hugging Face، Pexels، Pixabay) مع توثيق حيّ من ويكيبيديا والتفسير الميسّر.
