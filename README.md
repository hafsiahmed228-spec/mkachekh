- 🌐🎬 **استوديو الدبلجة بالدارجة التونسية + مونتاج `Auto B-Roll` الذكي (جديد v1.40):** ادبلج أي فيديو أجنبي أو عربي للدارجة التونسية الطبيعية بتزامن تلقائي مع اللقطات، أو خلّي المخرج الذكي يركّب فوق فيديوهاتك لقطات وصور `B-Roll` توضيحية كيف مشاهير اليوتيوب!
- ❓🌍 **تحدّي خمّن الدولة من خريطتها في 5 ثواني + صور المعالم الحقيقية وكاراوكي مضيء (جديد v1.40):** مسابقات خرائط وأعلام 3D ترند بعدّاد وكشف احتفالي، مع ظهور صور حقيقية للمدن والمعالم فوق الخريطة وكاراوكي يضوي كلمة بكلمة مع الصوت، ومضاعفة رصيد صوت Gemini البشري 6 مرّات!

- 🧬 **معلّم ومستنسخ ستايل المونتاج (جديد):** ابعث أي فيديو مرجعي، التطبيق يتعلّم إيقاع القصّ والألوان والكتابة متاعو ويخرّجلك فيديو كيفو بموضوعك وشخصياتك الجديدة بلا أغلاط!
