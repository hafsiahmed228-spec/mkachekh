## شنوّة يعمل؟
- 🎓 شرح: انت تحكي لوطة ولوحة متحرّكة فوقك تشرح كلامك (كيف ريلز الشروحات).
- 🎬 قصص فيديو كاملة بالذكاء الاصطناعي: نص، صور، صوت، ترجمة وموسيقى.
- 📖 القرآن، الحديث والأذكار في فيديوهات جاهزة.
- 🤖 مساعد ذكي يجاوب ويرسم صور ويحضّرلك أفكار فيديوهات.
- ✂️ قوالب شورتس: ابعث أي فيديو، يختار أقوى اللحظات ويزيد الموسيقى وحدو.
- 📅 خطة 30 يوم: فكرة فيديو كل نهار، تتصنع بضغطة.
- 🧩 ألغاز وتشويق، مسابقات، واحكي القصة بصوتك.

## كيفاش تنصّبو؟
1. اضغط على **تحميل التطبيق** فوق.
2. حلّ الملف `Mkachekh.apk` من التليفون.
3. كان التليفون يطلب، اسمح بـ «تثبيت تطبيقات من مصادر غير معروفة».
4. حلّ التطبيق، ادخل للإعدادات وحطّ مفتاح API متاعك (Groq أو Google AI Studio، مجاني).
