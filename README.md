## شنوّة يعمل؟
- 💬 **فيديوهات محادثات متحرّكة (جديد):** محادثات واتساب، إنستغرام DM وآيفون تطلع مساج بمساج مع أصوات التنبيه وقراءة بصوتين.
- 🎙️ **استوديو البودكاست والمناظرة 3D (جديد):** حوار أو مناظرة ساخنة بين مذيعَين مع موجات صوتية تتفاعل مع الكلام لحظة بلحظة.
- ⚽ **استوديو الكورة والمقارنات VS (جديد):** مباريات ونتائج حيّة من رابطة أبطال إفريقيا وأوروبا والدوريات الكبرى مع شعارات الفرق ومقارنات متحرّكة وتعليق حماسي.
- 🔗 **تحويل أي رابط لفيديو (جديد):** الصق رابط خبر، مقال، ويكيبيديا أو يوتيوب ويتحوّل لفكرة وهوك وسكريبت جاهز.
- ⚡ **معاينة حيّة فورية + طبيب الهوك وفلاتر الصوت (جديد):** شوف الفيديو في ثانية قبل الرندر، قيّم قوّة أوّل 3 ثواني من 100، وصفّي صوتك بفلاتر استوديو بدون إنترنت.
- 🧠 موّجه ذكاء تلقائي: يخدم مباشرة حتّى بلا مفتاح، ويدمج مفاتيحك المجانية (Groq، Cerebras، Google Gemini، Mistral، GitHub Models، Cloudflare، Hugging Face، Pexels، Pixabay) مع توثيق حيّ من ويكيبيديا والتفسير الميسّر.
- 🎭 دراما قصيرة: مسلسل بالحلقات، كل شخصية بصوتها ونفس وجهها.
- 📚 مكتبة برومبتات محترفة (فيديو، صور، هوكات).
- 🎓 شرح: انت تحكي لوطة ولوحة متحرّكة فوقك تشرح كلامك (كيف ريلز الشروحات).
- 🎬 قصص فيديو كاملة بالذكاء الاصطناعي: نص، صور، صوت، ترجمة وموسيقى.
- 📖 القرآن، الحديث والأذكار في فيديوهات جاهزة.
- 🤖 مساعد ذكي يجاوب ويرسم صور ويحضّرلك أفكار فيديوهات.
- ✂️ قوالب شورتس: ابعث أي فيديو، يختار أقوى اللحظات ويزيد الموسيقى وحدو.
- 📋 ملخّص فيديو طويل (حتى ساعتين) في دقيقة ولا 3.
- 📅 خطة 30 يوم: فكرة فيديو كل نهار، تتصنع بضغطة.
- 🧩 ألغاز وتشويق، مسابقات، واحكي القصة بصوتك.

## كيفاش تنصّبو؟
1. اضغط على **تحميل التطبيق** فوق.
2. حلّ الملف `Mkachekh.apk` من التليفون.
3. كان التليفون يطلب، اسمح بـ «تثبيت تطبيقات من مصادر غير معروفة».
4. حلّ التطبيق، ادخل للإعدادات وحطّ مفتاح API متاعك (Groq أو Google AI Studio، مجاني).
